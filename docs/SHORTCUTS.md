# NoorMD keyboard shortcuts

Press **F1** in the app to see this list, or **Ctrl+K** to search every command.

| Action | Shortcut |
|---|---|
| New document | Ctrl+N |
| Open file | Ctrl+O |
| Save | Ctrl+S |
| Save as | Ctrl+Shift+S |
| Print (PDF via *Microsoft Print to PDF*) | Ctrl+P |
| Command palette | Ctrl+K (or Ctrl+Shift+P) |
| Find | Ctrl+F |
| Find and replace | Ctrl+H |
| Next / previous match | Enter / Shift+Enter (in the find box) |
| Replace all | Ctrl+Enter (in the replace box) |
| Visual editor | Ctrl+1 |
| Markdown source | Ctrl+2 |
| Split view | Ctrl+3 |
| Focus mode | F11 (Esc to leave) |
| Show / hide sidebar | Ctrl+\ |
| Bigger / smaller / reset text | Ctrl+= / Ctrl+- / Ctrl+0 |
| Save revision snapshot | Ctrl+Alt+S |
| Browse revision snapshots | Ctrl+Shift+H |
| Preferences | Ctrl+, |
| Keyboard shortcuts | F1 |
| Undo / redo | Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) |
| Bold / italic | Ctrl+B / Ctrl+I |
| Close dialog, find bar or focus mode | Esc |

Mouse and keyboard extras:

- **Split divider:** drag it, double-click to reset it to 50/50, or focus it with Tab and
  use ← and →.
- **Sidebar edge:** drag it to resize, or focus it and use ← and →.
- **Links:** Ctrl+click opens a link while editing in Visual mode. In the preview a plain
  click opens it. You are always asked before NoorMD opens anything.
- **Opening files:** drop a `.md`, `.markdown` or `.txt` file anywhere on the window.

All shortcuts are handled in one place (the editor page), and the browser's own shortcuts
(reload, browser print, find, zoom) are switched off. A held-down Ctrl+S saves exactly once.
