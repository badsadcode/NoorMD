# NoorMD keyboard shortcuts

Press **F1** in the app to see this list, or **Ctrl+K** to search every command.

| Action | Shortcut |
|---|---|
| New document (new tab) | Ctrl+N or Ctrl+T |
| Open files (each in a tab) | Ctrl+O |
| Close tab | Ctrl+W (or middle-click the tab) |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab (also Ctrl+PageDown / Ctrl+PageUp) |
| Go to an open document (or, in a Vault, any note) | Ctrl+E |
| Open a menu | Alt + underlined letter (File = Alt+F …) · F10 then arrows |
| Find in Vault | Ctrl+Shift+F |
| Vault explorer | Ctrl+Shift+E (then arrows, Enter, F2 rename, Delete, Space to select) |
| Follow a [[wiki link]] | Ctrl+click it |
| Tab menu (Close Others, Copy Path, Pin…) | right-click a tab |
| Save (the visible tab only) | Ctrl+S |
| Save as | Ctrl+Shift+S |
| Print (PDF via *Microsoft Print to PDF*) | Ctrl+P |
| Command palette | Ctrl+K (or Ctrl+Shift+P) |
| Find | Ctrl+F |
| Find and replace | Ctrl+H |
| Next / previous match | Enter / Shift+Enter (in the find box) |
| Replace all | Ctrl+Enter (in the replace box) |
| Visual editor | Ctrl+1 |
| Markdown source | Ctrl+2 |
| Split view | Ctrl+3 |
| Focus mode | F11 (Esc to leave) |
| Show / hide sidebar | Ctrl+\ |
| Line width: Comfortable → Wide → Full width | Ctrl+Shift+W |
| Compact layout on / off | Ctrl+Shift+L |
| Spellcheck on / off | Ctrl+Shift+Y |
| Bigger / smaller / reset text | Ctrl+= / Ctrl+- / Ctrl+0 |
| Save revision snapshot | Ctrl+Alt+S |
| Browse revision snapshots | Ctrl+Shift+H |
| Preferences | Ctrl+, |
| Keyboard shortcuts | F1 |
| Undo / redo | Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) |
| Bold / italic | Ctrl+B / Ctrl+I |
| Heading 1–6 | Ctrl+Shift+1 … Ctrl+Shift+6 |
| Insert link | Ctrl+Shift+K |
| Insert code block | Ctrl+Shift+C |
| Indent / outdent (lists, Markdown) | Tab / Shift+Tab |
| Close dialog, find bar or focus mode | Esc |

### Music Bench (Creator's Bench)

| Action | Shortcut |
|---|---|
| Show / hide Music Bench | Ctrl+Shift+M |
| Play / pause | Ctrl+Alt+Space (or the media keys) |
| Next / previous track | Ctrl+Alt+→ / Ctrl+Alt+← |
| Edit current track (or the selected one in the list) | F2 |
| Triage the playing track: Favorite / Keep / Maybe / Skip / clear | Alt+1 / Alt+2 / Alt+3 / Alt+4 / Alt+0 |
| In the track list: play, triage, add to Up next, play next | Enter, 1–4 (0 clears), Q, N |
| In the edit dialog: Save / Save & Next / Cancel | Enter / Ctrl+Enter / Esc |
| Next theme | Ctrl+Shift+T |

Mouse and keyboard extras:

- **Split divider:** drag it, double-click to reset it to 50/50, or focus it with Tab and
  use ← and →.
- **Sidebar edge:** drag it to resize, or focus it and use ← and →.
- **Links:** Ctrl+click opens a link while editing in Visual mode. In the preview a plain
  click opens it. You are always asked before NoorMD opens anything.
- **Opening files:** drop a `.md`, `.markdown` or `.txt` file anywhere on the window.

AltGr keystrokes (for example AltGr+S for **ś** on Polish keyboards) are always typed as
letters and never trigger a shortcut.

All shortcuts are handled in one place (the editor page), and the browser's own shortcuts
(reload, browser print, find, zoom) are switched off. A held-down Ctrl+S saves exactly once.
